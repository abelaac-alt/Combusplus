Política de privacidad

Última actualización: 3 de agosto de 2026

1. Gestión de la aplicación

Combusplus está gestionada por A2C Solutions.

2. Datos del usuario

Combusplus no requiere registro y no solicita nombre, apellidos, correo electrónico, teléfono, documentos de identidad ni datos bancarios.

Los vehículos, consumos, capacidad del depósito, favoritos, descuentos, ajustes e historial se guardan en el propio dispositivo.

3. Ubicación

La aplicación puede utilizar la ubicación del dispositivo, con permiso del usuario, para encontrar gasolineras cercanas, calcular distancias y mostrar rutas.

La ubicación exacta no se conserva como parte del perfil del usuario.

4. Estadísticas opcionales

Cuando el usuario lo acepta, Combusplus puede registrar estadísticas técnicas y seudónimas para mejorar la aplicación, como:

  • tipo de dispositivo y sistema operativo;
  • versión de la aplicación;
  • funciones utilizadas;
  • ciudad o zona aproximada;
  • identificador técnico de instalación;
  • fecha de la última actividad.

Estas estadísticas no incluyen nombre, correo electrónico, teléfono, matrícula, vehículos guardados, favoritos, historial de repostajes ni ubicación exacta.

El usuario puede rechazar esta opción sin que ello impida utilizar la aplicación.

5. Finalidad

La información técnica se utiliza únicamente para prestar el servicio, calcular resultados, mantener la seguridad, corregir errores y mejorar Combusplus.

No se utiliza para publicidad personalizada ni se vende a terceros.

6. Permisos

  • Ubicación: para encontrar gasolineras cercanas y calcular trayectos.
  • Notificaciones: para avisos activados por el usuario.
  • Internet: para consultar precios, mapas y rutas.

7. Conservación y eliminación

Los datos guardados en el dispositivo permanecen hasta que el usuario los elimina, borra los datos de la aplicación o la desinstala.

Las estadísticas técnicas se conservan solo durante el tiempo necesario para analizar y mejorar el funcionamiento de Combusplus.

8. Cambios

Esta política podrá actualizarse cuando cambien las funciones de la aplicación. La versión vigente estará disponible desde Combusplus y desde su página oficial.
