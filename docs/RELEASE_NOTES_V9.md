# Novedades de Combusplus 9.0

- Backend integrado sin configuración visible para el usuario.
- Sesión anónima renovada automáticamente.
- Android Auto y comprobación de favoritas ya no dependen de abrir la WebView para renovar la sesión.
- Play Integrity conectado con el backend.
- Google Maps obligatorio en los workflows de publicación.
- Caché PWA renovada para evitar `config.js` obsoleto.
- Exportación local sin claves de infraestructura.
- Comparación real con coste equivalente y ahorro.
- Cálculo diferenciado de ida y vuelta o solo ida.
- Coste de repostaje visible.
- Migración SQL compatible con la función de limpieza existente.
- CodeQL y Dependabot añadidos.
- Versiones unificadas en web, backend y Android.
