# Lista de publicación en Google Play

## Artefacto

- [ ] AAB release generado por `Publicar Android (AAB y APK)`.
- [ ] `applicationId`: `com.grupomds.combusplus`.
- [ ] `versionCode`: 30.
- [ ] `versionName`: 8.0.0.
- [ ] Target API 36.
- [ ] Play App Signing activado.
- [ ] Clave de subida guardada de forma segura.

## Privacidad

- [ ] Datos legales reales añadidos a `web/privacy.html`.
- [ ] URL pública comprobada sin inicio de sesión.
- [ ] Enlace dentro de la aplicación comprobado.
- [ ] Seguridad de los datos completada con el comportamiento real.
- [ ] Declarada la ubicación utilizada para funcionalidad de búsqueda.
- [ ] Declarado el identificador de instalación y registros técnicos cuando corresponda.
- [ ] Confirmado que no hay publicidad ni SDKs adicionales no documentados.

## Permisos

- [ ] Ubicación aproximada y precisa explicadas en la ficha.
- [ ] No se solicita ubicación en segundo plano.
- [ ] Notificaciones solicitadas solo al activarlas.

## Calidad

- [ ] Pruebas en Android 8, 11, 13, 15 y 16.
- [ ] Pruebas con ubicación denegada y aproximada.
- [ ] Pruebas sin conexión y con servidor temporalmente caído.
- [ ] Pruebas de mapa Google y mapa alternativo.
- [ ] Pruebas de importe, depósito lleno, ida y vuelta y solo ida.
- [ ] Pruebas de comparación y cálculo del ahorro.
- [ ] Pruebas de widgets tras reinicio.
- [ ] Pruebas en Android Auto Desktop Head Unit y pista interna.
- [ ] Pruebas de actualización desde la versión anterior conservando datos.

## Integridad

- [ ] Proyecto de Cloud vinculado a Play Console.
- [ ] Cuenta de servicio de Play Integrity configurada.
- [ ] Número de proyecto configurado en GitHub.
- [ ] Modo `optional` durante la primera pista interna.
- [ ] Veredictos correctos comprobados.
- [ ] Modo `enforce` activado antes de producción.
