# Supabase para Combusplus 8.0

La instalación vigente está documentada en [docs/INSTALLATION_V8.md](docs/INSTALLATION_V8.md).

No utilices las variables antiguas `APP_ACCESS_TOKEN` o `COMBUSPLUS_APP_ACCESS_TOKEN`. La versión 8 usa sesiones anónimas firmadas por instalación, límites de uso y Play Integrity para Android.
